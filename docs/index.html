Features

        
Everything you'd walk back to your laptop for.

        
Hover a card. Each one is a thing people actually get up from the sofa to do.

      

      

        
01 / AI AGENTS
          

          
Answer AI agents with one tap

          
Claude Code, Codex, Gemini CLI or Aider keep working while you're out. When one asks "Do you want to proceed?" your phone buzzes with the question.

          
● Claude needs you · app
  Do you want to make this edit to auth.ts?
  ❯ 1. Yes   2. No

        

        
02 / DASHBOARD
          

          
All your agents on one screen

          
Who needs you, what's working and for how long, what just finished. Answer a waiting agent right from the list.

          
● Claude Code  ~/shop-app   needs you · 3 min
● Codex        ~/api        working · 22 min
✓ npm build    ~/web        4 files changed

        

        
03 / NOTIFY
          

          
Answer from the notification

          
Yes / No right on the notification on Android, with the app closed and the phone locked.

        

        
04 / POWER
          

          
Lid closed? Still works

          
On charger it answers instantly. On battery it wakes on a smart schedule (every 20 s right after you use it) and the app counts down to the second it connects.

        

        
05 / AUTO
          

          
Auto-approve safe steps

          
Opt-in. Steps like npm test are answered for you; anything risky (delete, push, deploy, sudo) still asks.

        

        
06 / CHANGES
          

          
See what it changed

          
"Finished · 4 files changed (+120 −8)". Tap See changes to read the diff on your phone.

        

        
07 / VOICE
          

          
Answer in your own words

          
Say "No, keep the old tests" and it goes to the agent as its next instruction.

        

        
08 / LOCALHOST
          

          
Your localhost, anywhere

          
Run npm run dev on the laptop and open it on your phone from any network. No tunnels, no deploys.

        

        
09 / TEAM
          

          
Share a live view

          
A view-only link for a teammate. Optionally let them press Yes / No on questions, nothing else. It expires.

        

        
10 / FILES
          

          
Files both ways

          
Grab a file or a database backup from the computer. Upload a photo straight into a project folder.

        

        
11 / ASK
          

          
Ask in plain English

          
"Free up port 3000" becomes the right command for your system, explained before it runs.

        

        
12 / COMPUTERS
          

          
All your computers

          
Laptop, desktop, a server: pair them all and switch with one tap on the name at the top.

How it works

        
Three steps. About five minutes.

      

      

        
$ npx pocket-terminal
Install on your computer
One line. It runs quietly in the background and starts at login.

        
✓ code 482 913 · approve? y
Scan the QR code
With the app on your phone. Both screens show the same 6-digit code; type y to approve.

        
● connected · direct · encrypted
Use it anywhere
Phone and computer talk directly. A free public board only passes the encrypted "hello".

Needs Node.js 18.20+. Run the line again any time to update; your pairing stays.

      

      

        
install pocket-terminal

        

          
          
          
          
        

        

          
Open Terminal and paste:

          
$curl -fsSL https://pocket-terminal.utsavdoye.com/install.sh | bash

  • no Node.js? brew install node

  • needs build tools once: sudo apt install -y build-essential python3

Security

        
It's your shell. It's built like it.

        
Security never depends on the code being secret: it's all open source. Read the full threat model.

        

          
npx pocket-terminal list


#  phone            paired      last seen
1  iPhone 15        12 Oct      now
2  Pixel 8          02 Nov      3 h ago

utsav@macbook ~ % npx pocket-terminal remove 2
✓ Pixel 8 locked out. Its key no longer works.

        

      

      
    
        
  • End-to-end encrypted. AES-256-GCM notes and a DTLS direct link. Nothing in the middle can read a character.
    • 
        
  • Only phones you approve. Each QR code works once, for 10 minutes, and only after you type y next to a matching code.
    • 
        
  • Lock any phone out from the computer in seconds. Each phone has its own key.
    • 
        
  • PIN-locked on the phone. 10 wrong tries wipe the key.
    • 
        
  • Nothing logged. Commands, output and file names never touch the log. Notifications are encrypted for your phone.
    • 
        
  • Share links are view-only, enforced on the computer, and they expire.

FAQ

        
Questions, answered.

      

      
Is it really free? Is there a server?
Free and open source (MIT). There's no server you run or pay for, and none that can read your data. A free public message board passes a few encrypted "hello" notes so the two devices can find each other; your live terminal goes directly between them.

      
How is it different from SSH or Tailscale?
Those assume your computer is awake and reachable. Pocket Terminal is built around a laptop that's asleep in your bag: it wakes itself briefly to check for work, runs it, replies, and sleeps again. Nothing to set up on your router, no account.

      
Can AI coding agents keep running with my laptop closed?
Yes. While a program is still working, the computer stays awake (on battery too, above 20%, for up to 2 hours after you last used it). When an agent like Claude Code, Codex or Gemini CLI stops to ask, your phone buzzes with the question. Tap it and answer.

      
What does it cost in battery?
Each check-in is a few seconds awake. Overnight that's typically a few percent. It never stays awake below 20% and stops waking below 10%.

      
Can I use it with more than one computer?
Yes. Pair each one (run npx pocket-terminal on it and scan its QR code from the app), then tap the computer's name at the top of the app to switch. Each has its own PIN. Notifications come from the one you used last.

      
I lost my phone. What now?
On your computer run npx pocket-terminal list, then npx pocket-terminal remove <number>. That phone is locked out within seconds, and its PIN-locked key is useless.

      
Which systems does it work on?
Computer: macOS, Windows 10/11, and Linux (laptops get the lid-closed features; servers simply stay awake). Phone: iPhone and Android, as an app you add to your home screen.

      
Does it work when I start the agent on my computer, or in VS Code?
Yes. Start any terminal agent with npx pocket-terminal run claude (or codex, gemini…): it runs in your window as usual and shows on your phone too, so you can walk away and carry on there. For Claude Code anywhere, including the VS Code extension, run npx pocket-terminal claude on once: when you're away from the computer, its permission questions come to your phone with Allow / Deny, and when you're at it they stay on screen. Chat panels without hooks, like Copilot Chat, can't be reached.

      
Can I answer without opening the app?
On Android, yes: questions show Yes / No buttons right on the notification, even with the app closed and the phone locked. On iPhone, web apps can't put buttons on notifications yet, so tap the notification and answer in the app.

      
Something isn't working
The help page covers installing, pairing, connecting, notifications and uninstalling. Still stuck? Ask in Discussions.
