Installing

"command not found: node" or "npx: command not found"

Install Node.js 18.20 or newer, then run the install line again: nodejs.org (LTS), or brew install node on a Mac, or winget install OpenJS.NodeJS.LTS on Windows.

Linux: "make: not found" or "g++: not found"

The terminal part is compiled once on Linux. Install the build tools and run the install line again:

sudo apt install -y build-essential python3      # Ubuntu, Debian
sudo dnf install -y make gcc-c++ python3          # Fedora
sudo pacman -S --needed base-devel python         # Arch

Mac: it asks for my password

Once, so it can keep the Mac reachable with the lid closed and set wake-up alarms. It can only run four exact pmset sleep commands, nothing else.

Windows: PowerShell says scripts are disabled

Use the one line exactly as shown on the install section (irm … | iex), or use npx pocket-terminal. Neither needs admin rights.

Pairing

iPhone: I paired, but the Home Screen app asks to pair again

iPhone keeps Home Screen apps separate from Safari. Pair inside the Home Screen app: open it, tap Scan QR code.

The QR code doesn't work

Each code works once, for 10 minutes. Make a new one with npx pocket-terminal pair. No camera? Tap Paste pairing link in the app and paste the link the computer prints.

The 6-digit codes don't match

Type n on the computer. Someone else may have scanned your QR. Make a new code somewhere private.

Can't connect

It says "Waiting for …"

  • Check the computer is on and online. Asleep is fine; it wakes every minute or two and connects by itself.
  • Check the program is running: npx pocket-terminal logs should show recent lines.
  • Restart it: Mac launchctl kickstart -k gui/$(id -u)/com.pocketterminal.agent · Linux systemctl --user restart pocket-terminal · Windows: run the install line again.
  • Removed this phone on the computer? In the app, open ⋯ → Settings → Unpair, and pair again.

"This network blocks the direct link"

Some college and office Wi-Fi blocks direct connections. Commands still work through the encrypted backup route, a few seconds slower. The live terminal comes back on another network (mobile data usually works).

Lid closed & battery

  • On charger it stays awake and answers instantly, lid closed or not.
  • On battery it sleeps and wakes every 1–2 minutes to check for you. Set the interval in the app: ⋯ → Power and battery.
  • Below 20% it stops staying awake; below 10% it stops waking up, so your battery never dies.
  • Windows can't tell when the lid is closed, so it sleeps after 10 minutes without keyboard or mouse use. Some "Modern Standby" laptops ignore wake-up alarms on battery: keep them plugged in, or use Instant mode.

AI agents

  • Started on the computer: run npx pocket-terminal run claude (or any command). It shows in your window as usual and on your phone too. Close the window or walk away: it keeps running, and you carry on from the phone.
  • Claude Code anywhere, even in VS Code: run npx pocket-terminal claude on once, then restart Claude Code. Away from the computer (no typing for a minute), its permission questions come to your phone with Allow / Deny. At the computer they show on screen as usual. While it works the computer stays awake, and your phone hears when it finishes. Off: npx pocket-terminal claude off.
  • See them all: ⋯ → Agents & terminals shows every terminal, which one needs you, what's working and what finished. Answer a waiting one right there.
  • Answer from the notification: on Android, questions show Yes / No buttons. On iPhone, tap the notification and answer in the app.
  • Answer in your own words: tap 🎤 Say on a question and type or speak. On an agent's menu it picks "No, tell it what to do instead" and sends your words.
  • Auto-approve safe steps: ⋯ → Settings, off by default. Says Yes only when the question has one of your safe words and none of the risky ones (delete, push, deploy, sudo…).
  • See what changed: in a git folder, a finished agent shows files changed. Tap See changes for the diff.

Notifications

iPhone: "Turn on" does nothing, or nothing arrives

  • Needs iOS 16.4 or newer and the app opened from the Home Screen (not Safari).
  • Allow them: iPhone Settings → Notifications → Pocket Terminal.
  • In the app: ⋯ → Settings → Phone notifications → Test.

When do I get one?

When a program finishes after running a while, or stops to ask you something (an AI agent's "Do you want to proceed?", a [y/N] question), and you're not looking at that terminal. Tap it to open that exact terminal.

Local websites

  • Start your dev server first (npm run dev…), then ⋯ → Local websites. Not listed? Type the port.
  • Only your computer's own localhost is reachable.
  • Live reload (WebSockets) doesn't work yet: tap reload to see changes. Links to other ports don't work either.

Files

⋯ → Files: tap a file to put its path in the terminal (handy for a command or an AI agent) or download it to your phone, or Upload here to save a file into the folder you're in. Up to 250 MB each. Needs the live connection (not the backup route).

Phones & sharing

npx pocket-terminal list          # phones that can connect
npx pocket-terminal remove 2      # lock phone number 2 out (or a name, or "all")
npx pocket-terminal pair          # pair another phone

Share a live view: ⋯ → Agents & terminals → Share live view, pick how long (30 min to 1 day), send the link. They can watch, not type. Tick Let them answer to also let them press Yes / No on its questions, nothing else. Stop sharing ends it at once.

Update & uninstall

npx pocket-terminal@latest        # update (or run your install line again)
npx pocket-terminal uninstall     # remove it; add --purge to delete the pairing key too

Then in the app: ⋯ → Settings → Reload app to get the newest phone app.

Logs

npx pocket-terminal logs, or open ~/.pocket-terminal/agent.log (Windows: %USERPROFILE%\.pocket-terminal\agent.log). It never contains your commands, their output, or file names, so it's safe to paste into an issue.
