# Code of conduct

Pocket Terminal is a small open-source project. Everyone is welcome here, whatever their experience, background or identity.

## Be kind, be useful

- Be respectful and patient, especially with people who are new.
- Talk about the code and the idea, not the person.
- Assume good intent. Ask before assuming.
- No harassment, insults, sexual content, or personal attacks. No sharing other people's private information.

## If something goes wrong

If someone makes you feel unwelcome, contact the maintainer privately through [GitHub](https://github.com/utsavdoye) or open a private report in this repository (Security → Report a vulnerability works for this too). Reports are kept private.

The maintainer may edit or remove comments, issues and pull requests that break these rules, and may block people who keep breaking them.

This code of conduct is based on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
